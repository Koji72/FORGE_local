# Changelog

All notable changes to Forge will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial project structure with 8 Rust crates
- Technical specification and documentation
- Database schema with SQLCipher encryption support
- CI/CD pipelines for testing and releases
- JSON schemas for all 5 agent types
- Plugin manifest and permission system design

### Documentation
- Technical specification (spec-tech.md)
- API IPC reference (api-ipc.md)
- Sync protocol specification (sync-protocol.md)
- Threat model with STRIDE analysis (threat-model.md)
- Plugin development guide (plugin-dev.md)
